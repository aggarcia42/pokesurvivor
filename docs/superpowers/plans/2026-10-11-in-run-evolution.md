# In-run Evolution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The partner evolves during the run at its real evolution levels on a 1-100 level curve, starting small pays an XP bonus, permanent upgrades follow the whole family, and the upgrades screen works on the chosen partner.

**Architecture:** A once-generated `js/data/evolutions.js` (PokeAPI chains, cached raw JSON) feeds hand-written helpers in `js/data/evos.js`. `Player` gains `MAX_LEVEL`, a new `xpFor`, per-level growth and `evolveTo(dex)`; `gainXp` reports which levels earn a card pick and which evolution is due. `G.LevelUp.picksAt(level)` holds the card schedule; branch evolutions reuse the level-up screen with an `evo-branch` card type. `G.DB.upgradesOf` resolves to the family base with a v3→v4 save migration. Coop syncs the current `dex` in the state array.

**Tech Stack:** Vanilla JS (ES2020) on Canvas 2D; `node tools/test.js` (vm sandbox, 65 tests today); Python 3 for the one-off data fetch; `node tools/build.js` for the bundle; Spanish strings with English entries in `js/data/lang-en.js`.

**Spec:** `docs/superpowers/specs/2026-10-11-in-run-evolution-design.md`

## Global Constraints

- Spanish-first game: every new player-facing Spanish string gets an entry in `js/data/lang-en.js` (key = exact Spanish text, `{x}` for holes).
- Edit `dev.html`, never `index.html`; new scripts go in the `<!-- scripts:begin -->` block in dependency order.
- No emojis; icons from `G.Icons`.
- Numbers from the spec: `MAX_LEVEL = 100`; `xpFor(L) = floor((3 + 1.2·L + 0.25·L^1.5) × 4.19)`; growth +1% base HP and +0.5% attack per level; card picks at every level 2-20, every 2nd level 22-50, every 3rd 53-98, and 100 (37 picks by 60, 51 by 100); trade evolutions 50, every other non-level trigger 36; stage XP bonus +30% base / +15% middle / 0 final; level-based formulas rescaled by ×0.4 (burn and reactions `0.06 → 0.024`, Casco Dentado `4 → 1.6`, bomb `14 → 5.6`); mission level goals 20/30/38; achievement level goals 38 and 75.
- Grep with `--include=*.js` and exclude `js/app.min.js`.
- Commit messages in Spanish ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Run `node tools/test.js` before every commit.
- The data fetch runs once, needs the network, and must cache raw JSON under `tools/cache/pokeapi/` (git-ignored via `tools/cache/`).

## Review Focus

1. **A species missing from `G.EVOS`** (new sprite added later, or a fetch failure): the game must treat it as a single-stage family with the +30% bonus and never throw. → Task 1 test `especie sin entrada se comporta como familia de una etapa`.
2. **Gaining several levels in one pickup that cross an evolution level and a scheduled pick**: exactly one evolution and the right number of picks. → Task 3 test `varios niveles de golpe: una evolución y los picks de la agenda`.
3. **Evolving while max HP has been raised by Vigor**: the Vigor HP must survive the species swap, and HP ratio must be kept. → Task 3 test `evolveTo conserva la proporción de vida y los +20 de Vigor`.
4. **An old save with upgrades on two members of one family** (Charmander and Charizard both upgraded before this change): the migration must keep the best of each and delete the species keys. → Task 5 test `migración v4 funde las mejoras de una familia`.
5. **A coop puppet whose state carries a dex the client cannot resolve** (newer client): puppet keeps its species, no throw. → Task 3 test `un compañero ignora un dex desconocido`.

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
Baja UNA vez las cadenas de evolución de PokeAPI y las deja en
js/data/evolutions.js. El juego no toca internet.

    python tools/fetch_evolutions.py

Reglas (ver docs/superpowers/specs/2026-10-11-in-run-evolution-design.md):
  level-up con min_level  -> ese nivel
  trade                   -> 50
  cualquier otra cosa     -> 36 (piedras, amistad, objetos, lugares...)
Los destinos que no están en el juego (formas regionales...) se descartan.
Las respuestas crudas se guardan en tools/cache/pokeapi/ para no volver a bajarlas.
"""
import io, json, os, re, urllib.error, urllib.request
from concurrent.futures import ThreadPoolExecutor

API = 'https://pokeapi.co/api/v2'
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
OUT = os.path.join(ROOT, 'js', 'data', 'evolutions.js')
CACHE = os.path.join(ROOT, 'tools', 'cache', 'pokeapi')
TRADE_LVL, OTHER_LVL = 50, 36


def game_dexes():
    src = io.open(os.path.join(ROOT, 'js', 'data', 'pokedex.js'), encoding='utf-8').read()
    return [int(m) for m in re.findall(r'^\s*\{"dex":(\d+),', src, re.M)]


def get(url, retries=3):
    os.makedirs(CACHE, exist_ok=True)
    key = re.sub(r'[^a-z0-9]+', '_', url.replace(API + '/', '').lower()).strip('_') + '.json'
    path = os.path.join(CACHE, key)
    if os.path.exists(path):
        return json.load(io.open(path, encoding='utf-8'))
    for _ in range(retries):
        try:
            req = urllib.request.Request(url, headers={'User-Agent': 'pokesurvivor/1.0'})
            with urllib.request.urlopen(req, timeout=40) as r:
                data = json.load(r)
            io.open(path, 'w', encoding='utf-8').write(json.dumps(data))
            return data
        except urllib.error.HTTPError as e:
            if e.code == 404:
                return None
        except Exception:
            pass
    return None


def level_for(details):
    """Nivel de evolución a partir de la lista evolution_details de PokeAPI."""
    if not details:
        return OTHER_LVL
    for d in details:                       # si alguna variante da nivel, ese
        if d.get('trigger', {}).get('name') == 'level-up' and d.get('min_level'):
            return int(d['min_level'])
    if any(d.get('trigger', {}).get('name') == 'trade' for d in details):
        return TRADE_LVL
    return OTHER_LVL


def species_id(url):
    return int(url.rstrip('/').split('/')[-1])


def main():
    dexes = game_dexes()
    in_game = set(dexes)
    print(f'{len(dexes)} especies del juego; bajando species para saber su cadena...')
    chain_urls = {}
    with ThreadPoolExecutor(max_workers=8) as ex:
        for dex, s in zip(dexes, ex.map(lambda d: get(f'{API}/pokemon-species/{d}'), dexes)):
            if s and s.get('evolution_chain'):
                chain_urls[dex] = s['evolution_chain']['url']
            else:
                print(f'  ! species {dex} sin cadena')
    urls = sorted(set(chain_urls.values()))
    print(f'{len(urls)} cadenas...')
    chains = {}
    with ThreadPoolExecutor(max_workers=8) as ex:
        for url, c in zip(urls, ex.map(get, urls)):
            if c:
                chains[url] = c['chain']
            else:
                print(f'  ! cadena {url} no disponible')

    evos = {}

    def walk(node, fam, stage_parent_in_game):
        """Recorre la cadena. `fam` = primera especie del juego por encima (o None)."""
        me = species_id(node['species']['url'])
        here = me in in_game
        my_fam = fam if fam is not None else (me if here else None)
        if here:
            evos[me] = {'fam': my_fam, 'evo': []}
        for child in node.get('evolves_to', []):
            cid = species_id(child['species']['url'])
            if here and cid in in_game:
                evos[me]['evo'].append({'to': cid, 'lvl': level_for(child.get('evolution_details'))})
            elif not here and cid in in_game and stage_parent_in_game is not None:
                # El padre no está en el juego (p. ej. un bebé sin sprite): el hijo cuelga del abuelo.
                evos[stage_parent_in_game]['evo'].append({'to': cid, 'lvl': level_for(child.get('evolution_details'))})
            walk(child, my_fam, me if here else stage_parent_in_game)

    for url, chain in chains.items():
        walk(chain, None, None)
    for d in dexes:                          # los que no salen en ninguna cadena: familia de uno
        evos.setdefault(d, {'fam': d, 'evo': []})

    lines = [
        '/* ============ evolutions.js — GENERADO, no editar a mano ============',
        ' * Lo produce tools/fetch_evolutions.py (cadenas de evolución de PokeAPI, bajadas una vez).',
        ' * dex -> { fam: especie base de la familia, evo: [{ to, lvl }] }',
        ' * Intercambio = nivel 50; piedras, amistad y demás = 36. Ayudas en js/data/evos.js.',
        ' */',
        'G.EVOS = {',
    ]
    for d in sorted(evos):
        lines.append(f'  {d}: ' + json.dumps(evos[d], separators=(',', ':')) + ',')
    lines += ['};', '']
    io.open(OUT, 'w', encoding='utf-8', newline='\n').write('\n'.join(lines))
    n_evo = sum(1 for e in evos.values() if e['evo'])
    print(f'{len(evos)} especies, {n_evo} con evolución -> js/data/evolutions.js')


if __name__ == '__main__':
    main()
```

```js
/* ============ evos.js — ayudas sobre las cadenas de evolución ============
 * Los datos están en js/data/evolutions.js (generado). Una especie sin entrada
 * se trata como familia de una sola etapa.
 */
G.Evos = (() => {
  const E = dex => G.EVOS[dex] || { fam: dex, evo: [] };

  /** Especie base de la familia. */
  function family(dex) { return E(dex).fam; }

  /** Siguientes etapas: [{ to, lvl }] (varias en las ramas tipo Eevee). */
  function next(dex) { return E(dex).evo; }

  /** Toda la familia en orden de cadena (recorrido en anchura desde la base). */
  function lineOf(dex) {
    const out = [], seen = new Set();
    const queue = [family(dex)];
    while (queue.length) {
      const d = queue.shift();
      if (seen.has(d)) continue;
      seen.add(d); out.push(d);
      for (const x of next(d)) queue.push(x.to);
    }
    return out;
  }

  /** 0 = base, 1 = intermedia, 2 = final (profundidad desde la base). */
  function stage(dex) {
    const fam = family(dex);
    if (fam === dex) return 0;
    const depth = (d, k) => {
      if (d === dex) return k;
      for (const x of next(d)) { const r = depth(x.to, k + 1); if (r >= 0) return r; }
      return -1;
    };
    const k = depth(fam, 0);
    return k < 0 ? 0 : Math.min(2, k);
  }

  /** Bonus de experiencia por empezar pequeño: base +30%, intermedia +15%, final 0. */
  const BONUS = [0.30, 0.15, 0];
  function bonusFor(dex) { return BONUS[stage(dex)]; }

  return { family, next, stage, lineOf, BONUS, bonusFor };
})();
```

   * Suma experiencia. Devuelve { levels, picks, evo }: niveles subidos, cartas
   * ganadas según la agenda (G.LevelUp.picksAt) y, si algún nivel desbloquea
   * una evolución, { options } con las etapas posibles (ver evolveTo).

  gainXp(amount) {
    const r = { levels: 0, picks: 0, evo: null };
    if (this.level >= Player.MAX_LEVEL) { this.xp = 0; return r; }
    this.xp += amount * this.xpMul;
    while (this.xp >= this.xpNext && this.level < Player.MAX_LEVEL) {

    }
    if (this.level >= Player.MAX_LEVEL) this.xp = 0;

  evolutionDue() {
    const opts = G.Evos.next(this.dex).filter(x => x.lvl <= this.level && G.DEX_BY[x.to]);

  }

  /**
   * Evoluciona en plena run: cambia especie, sprite, stats y tipos. Se quedan
   * movimientos, pasivas, objeto, nivel y experiencia. La vida máxima se
   * recalcula con la vida de la nueva especie (y su crecimiento por nivel)
   * conservando lo demás (Vigor, mejoras) y la proporción de vida actual.
   */
  evolveTo(dex) {
    const to = G.DEX_BY[dex];
    if (!to || dex === this.dex) return false;
    const from = this.mon;
    const growth = 1 + (this.level - 1) * 0.01;
    const ratio = this.maxHp > 0 ? this.hp / this.maxHp : 1;
    this.maxHp = this.maxHp - from.hp * growth + to.hp * growth;

    this.anim.dir = dir;
    this.r = G.Sprites.bodyRadius(dex); this.bodyH = G.Sprites.bodyHeight(dex);

    this.invuln = Math.max(this.invuln || 0, 1);
